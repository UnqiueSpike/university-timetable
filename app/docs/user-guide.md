# 使用说明

## 登录与退出

使用管理员开通的账户。大学邮箱格式不代表大学身份已核实；当前不开放自助注册、找回密码或 SSO。需要账户或密码帮助时联系大学指定支持人员。兼具学生和教师身份时，入口随实际授权显示，不通过切换界面获得额外权限。退出后受保护数据立即隐藏，会话失效需重新登录。

本地演示者可查看被忽略的 .local-accounts.json。不要把这些测试账户带入正式环境；合成课程位于 2026-09-21 所在周。

## 学生

My timetable 使用左右按钮、Today 或日期选择器切换周。点击课程查看时间、地点、类型、容量、来源、验证状态及教师补充。时间全部按 Australia/Sydney；Unknown 不等于零。来源失败提示表示保留最后成功导入，并不代表本周没有课。Announcements 只显示发给你的有效公告。

Shared Timetables → Create Share：选择受控接收人、需要分享的一周、Full Timetable 或 Availability Only、7/30 天期限，再明确同意。Full 包含课程名、类型、时间、地点；Availability 仅时间。复制链接后由你提供给接收人，系统不会自动发送邮件或消息。接收人登录后打开链接比较本人和获准课表。链接失效、不是指定接收人或超出分享区间时，页面显示不可用。

撤销：在 Sent 列表点 Revoke，确认后停止后续读取；不会删除接收人此前自行保存的内容。到期自动失效。页面中的 Active 只表示未到期/撤销，若管理员撤销成员或身份资格，实际读取仍可能拒绝。

## 教师

Staff Workspace 只列授权课程。Edit supplement 只写补充文字，不能覆盖来源的时间、地点或容量。编辑时遇到版本冲突，先保存自己的草稿文字，再关闭并重开取得最新版本，不自动覆盖其他人修改。

Management 创建公告草稿，选择 COURSE、CLASS 或获准 GROUP。CLASS 只对应这一班，多个目标合并；发布前核对范围。草稿只有作者可管理，发布后不能直接编辑，需要撤回并创建新草稿。撤回后学生不再看到有效公告。Audit Log 需单独权限，可查看授权范围内的事件与前后值。

## 更新与故障

Updates connected 表示同步连接正常。教师修改和权限变化会自动触发重新查询；分享到期也会定期重新检查。断线时隐藏受保护内容，连接恢复后重新认证和读取；失败时点击 Retry connection。查询失败显示错误，不显示空课表。浏览器翻译可能改变文案；动态同步状态保留英文以免旧翻译掩盖连接状态。

可用 Tab/Shift+Tab 移动焦点、Enter/Space 激活按钮、Escape 关闭详情。窄屏使用课程列表与可横向滚动的表格。支持人员排查时可提供出现错误的时间和操作，勿发送密码或 Cookie。
