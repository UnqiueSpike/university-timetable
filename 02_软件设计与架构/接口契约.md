# 接口契约

以下为接口设计初稿，具体字段和认证方式待确认；不预设必须使用 tRPC 或其他框架。

## 查询个人课程表

**关联需求：**US-02 查看个人课程表、US-03 查看容量与数据可信度。

**用途：**查询当前登录学生在指定时间范围内的课程安排。

**建议接口：**`GET /api/me/timetable`。如采用 RPC，可映射为同等功能的查询操作。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| start | 带时区的 ISO 8601 时间字符串 | 是 | 查询开始时间，包含该时刻 |
| end | 带时区的 ISO 8601 时间字符串 | 是 | 查询结束时间，不包含该时刻；必须晚于 start |

身份通过已确认的认证机制传递，不接受客户端指定学生 ID。返回与查询区间重叠的课程，即课程开始时间早于 end，且结束时间晚于 start。

查询时间范围上限及响应性能指标需结合试点数据规模确认。

### 返回数据

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| items | 数组 | 课程表条目；确实没有课程时返回空数组 |
| items[].id | 字符串 | 课程表条目唯一标识 |
| items[].subject | 对象 | 科目代码 code 和名称 name |
| items[].type | 字符串或 null | 课程类型，如 Lecture、Tutorial |
| items[].startTime / endTime | 时间字符串 | 带时区的课程起止时间 |
| items[].location | 字符串或 null | 地点；未知时为 null |
| items[].capacity | 对象或 null | total 为总容量，available 为可用名额；各值可为 null，零表示已知为零 |
| items[].source | 对象 | name 为来源名称，kind 为 official、test 或 supplementary |
| items[].verificationStatus | 字符串 | verified、unverified 或 supplementary；判定规则待客户确认 |
| items[].updatedAt | 时间字符串或 null | 本系统最后更新该条目的时间，不代表源系统实时状态 |
| lastSyncedAt | 时间字符串或 null | 课程表数据最近一次成功接入时间 |
| dataStatus | 字符串 | current、stale 或 unknown；新鲜度判定阈值待确认 |

容量字段的业务定义及来源需客户确认。若容量与课程表来源或更新时间不同，应分别记录其来源和时间，接口字段随数据确认结果补充。

**成功返回示例（模拟数据）：**

```json
{
  "items": [
    {
      "id": "entry-demo-001",
      "subject": { "code": "DEMO1001", "name": "示例课程" },
      "type": "Lecture",
      "startTime": "2026-09-15T09:00:00+10:00",
      "endTime": "2026-09-15T10:00:00+10:00",
      "location": "示例教学楼 101",
      "capacity": { "total": 100, "available": null },
      "source": { "name": "批准的测试数据集", "kind": "test" },
      "verificationStatus": "unverified",
      "updatedAt": "2026-09-15T08:00:00+10:00"
    }
  ],
  "lastSyncedAt": "2026-09-15T08:00:00+10:00",
  "dataStatus": "unknown"
}
```

### 权限与业务规则

- 服务端从登录身份确定学生，只返回其本人课程表；他人分享的课表通过单独的分享接口查询。
- 按课程开始时间排序；开始时间相同时按条目 ID 排序。
- 未知地点、容量或可用名额不伪造为有效值；测试数据不标记为已验证的正式数据。
- 数据源暂不可用但存在可用历史数据时，可返回历史数据并标明过期或未知状态；没有可用数据时返回错误，不能用空数组掩盖失败。
- 时间比较按实际时刻进行，前端按明确的展示时区显示，避免夏令时造成偏差。

### 异常情况

以下状态码适用于建议的 HTTP 接口；采用 RPC 时保留对应错误语义。

| HTTP 状态码 | 错误码 | 情况 |
| --- | --- | --- |
| 400 | INVALID_TIME_RANGE | 时间缺失、格式无效，或 end 不晚于 start |
| 401 | UNAUTHENTICATED | 未登录或登录状态失效 |
| 403 | FORBIDDEN | 当前身份无权访问学生个人课程表功能 |
| 503 | TIMETABLE_UNAVAILABLE | 课程表数据暂不可用，且没有可返回的历史数据 |
| 500 | INTERNAL_ERROR | 系统内部错误；不向客户端暴露堆栈或数据库细节 |

```json
{
  "error": {
    "code": "UNAUTHENTICATED",
    "message": "请先登录后查看课程表。"
  }
}
```

### 验收要点

- 已登录学生能查询本人在指定区间内的课程，不能通过篡改参数获取其他学生的数据。
- 课程结束时间等于 start，或开始时间等于 end 时，不计入结果。
- 无课程返回空数组；加载失败返回明确错误或带状态的历史数据。
- 容量未知与零名额能够区分，来源及验证状态与数据依据一致。
